Z.AI workflow assistant

Describe a browser task in plain language. AutoFlow sends the request to a local bridge on your computer, which calls Z.AI and returns editable workflow JSON. Your Z.AI API key stays in the local bridge and is never stored in GitHub Pages.

Start the local bridge in zai-bridge/, then test the connection.


          
Safety

          
The assistant only generates workflow steps. It does not execute them. AutoFlow keeps manual confirmation for actions such as publish, delete, send, purchase, pay, approve, and other irreversible clicks.

How AutoFlow works

          
A normal website cannot safely control arbitrary tabs on other websites. AutoFlow therefore separates the workflow designer from the automation runner.

          

            Web app→Workflow JSON→Local Playwright runner→Target website
          

          
Recommended first automation

          
Record the logic manually in the builder, replace changing values with variables, validate it, then execute it with the local runner.

          
Safety

          
Add a Confirm step before irreversible actions such as publish, delete, send, purchase, approve, or account changes. Avoid storing passwords in workflow files.
